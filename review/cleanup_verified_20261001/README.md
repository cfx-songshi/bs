## 校验和清理方式

1. 确认本地提交与 GitHub main 一致，逐文件检查该提交中的 Git LFS 指针。
2. 比对本机数据长度和 SHA-256。
3. 从 GitHub LFS 独立下载每个候选对象，计算完整内容的 SHA-256；不使用本地缓存代替下载。
4. 所有下载通过后，再次检查本机文件未变化，才将实际数据替换为小型 LFS 指针。云端文件不删除。
5. 仅对同一对象的已校验本地缓存清理；未确认云端备份的缓存保留。

`plan.json` 是逐文件计划；`remote_verification.json` 是云端下载核验记录；`receipt.json` 是实际执行记录。此前2026-09-26已经清理的大型Abaqus数据不重复计入本次释放空间。
