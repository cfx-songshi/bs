# 碳纤维板落球冲击：P2路线实物对接

状态：已实现并实际运行完整板面Kirchhoff薄板Rayleigh–Ritz落球耦合求解；不是3D有限元。尚无实物验证，局部接触力与原始应变仍未充分空间收敛。最初规划已落实为明确标注假设的机械基准，详见下方复算入口。

## 1. 已确定的路线

500×400×2 mm碳纤维板，水平放置，周边框架夹持；自由落球产生冲击，PZT-5A接收，DAQ122记录。保留原guided_wave_v2，冲击模型独立建立。

P2来源为知识库SMS论文01.pdf：PDF第15页§3.1给出落球实验；第16页图17显示框架夹具；第17页表2给出球材料、球径、落高，并明确仿真周边全自由度固定。实物夹具不是已证实的理想固支。原论文对象为铝蜂窝夹层板，本项目对象为碳纤维实心层合板，不能移植其材料模型、损伤阈值或定位精度。

## 2. 参数管理

specimen.json是本路线的初始输入清单。数值使用SI单位，null表示尚未确定，禁止当作零处理。

- 订单值：板500×400×2 mm；PZT平面尺寸15×15 mm。
- 商家标称：板密度1650 kg/m³，厚度公差±0.1 mm，内部0/90交叉对称铺层及两面3K织物。不能从这段描述推导唯一层序。
- 用户确认：PZT-5A。
- 商家PZT表：密度7600 kg/m³，介电常数约2000，d33约450 pC/N，d31栏数值204 pC/N但符号未明确。不得与其他厂家参数无说明地拼成完整材料矩阵。
- 待测/待选：夹持宽度及净跨、球质量及直径、落高、PZT厚度、胶层、电路和材料刚度。

名义整板质量为0.5×0.4×0.002×1650=0.66 kg，不含传感器和胶层。实际称重和厚度测量用于核对，不强行让实测符合该值。

## 3. 第一轮实验流程

1. 记录板编号、两面照片、边缘方向、厚度和质量；定义左下外角为原点，长边为x轴。
2. 固定周边夹具，记录夹持宽度、开口净跨、螺栓位置和统一紧固流程；传感器和导线避开夹具。
3. 暂拟4片PZT中心位于(75,75)、(425,75)、(425,325)、(75,325) mm。此布置是本项目设计值，安装前检查夹具净空。
4. 核对板卡真实型号、输入量程、过采样、每通道采样率和前端；检查PZT电极与导电碳板的绝缘，明确输入保护及接地，不把芯片极限当成板卡允许输入。
5. 保存静态背景记录，检查缺失点、通道同步、饱和及工频干扰。暂拟200 kSPS/通道，预触发5 ms、后触发50 ms；不支持预触发时先连续记录再截取。这些是采集设计值，不是P2原文值。
6. 中心位置先试采，再在固定球、固定高度、固定夹持下重复10次。记录实际落点与重复弹跳；重复弹跳、位置偏离等保留原因标记，不静默删除。
7. 信号质量和重复性通过后，扩展位置。论文6/8/10 mm、160/250/360 mm是参考参数范围，不直接作为本板首轮执行清单。

只在输入幅值、夹持和采集条件可追溯时比较仿真与实测。没有独立检测结果时，不把冲击后的波形变化标为已产生分层。

## 4. 仿真实施顺序

1. 建立完整板面层合壳/板机械模型，检查总质量、边界和健康固有频率；对于未知层序与刚度，明确采用的替代层序及来源，并做敏感性分析。
2. 以明确选定的球质量、初速度和接触关系求解瞬态响应。局部接触/厚度响应必要时采用局部实体细化。mgh不能替代接触力时程，也不能直接证明无损。
3. 先输出板位移、应变及15×15 mm贴片区域的应变分布/积分，不把单节点位移改标为电压。
4. 核对PZT厚度、极化、完整材料矩阵、胶层和负载后建立机电接收模型；纳入板卡传递函数、采样和量化再对比电压。
5. 分别做空间网格与时间步敏感性、接触穿透及能量平衡检查；边界刚度单独变化以评估夹具不确定性。
6. 用实測响应做校准时，另留位置和重复试验验证，不能在同一数据上调参后宣称独立验证。

标准AD7606模拟滤波器的标称-3 dB带宽约22 kHz，200 kSPS不代表可平坦采集100 kHz。以真实板卡配置及校验为准。资料：https://www.analog.com/en/products/ad7606.html

### 方程和符号

采用w=sum(q_ij*x²(1-x)²*P_i(2x-1)*y²(1-y)²*P_j(2y-1))，x/y在净跨内归一化，P为Legendre多项式。该基严格满足四边位移与法向斜率为零。刚度由正交板弯曲能量积分，质量由rho*h积分；Gauss积分后解广义特征问题并质量归一化。完整保留所选基空间的模态。

正z和w取向下；顶部z=-h/2，应变为+h/2乘曲率。报告输出顶部15×15 mm区域平均(epsilon_xx+epsilon_yy)，不代表PZT电压或接线极性。

接触力F=k*max(z_ball-w_contact,0)^1.5；球和板受到等大反向力。初始球速sqrt(2*g*height)，板初始静止；之后保留球重力。机械能包含板动能、弯曲能、球动能、2/5*k*delta^2.5接触储能及-m*g*z_ball重力势能。接触力由状态求解，不是预设半正弦。

### 数据和验证限制

5 µs输出是未滤波机械采样，未实现真实模拟抗混叠、电路、量化与PZT转换。高阶原始应变不作为DAQ可测信号或到达时间精度依据。独立各向同性方板频率检查约35.99只验证方法特例；最高阶时间步检查、空间收敛和实物验证是三件不同的事。

当前Hertz系数为层合板接触代理，未知真实织物层、接触本构、胶层和PZT负载。空间截断仍显著影响局部响应，即使低阶频率与总挠度趋于稳定，也不能将接触力峰值、损伤或定位精度当成已验证结果。
