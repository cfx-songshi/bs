# 缺失数据、当前处理和获取方法

本清单针对500×400×2 mm碳板、PZT-5A、DAQ122和P2落球路线。所有临时参数见simulation_config.json；specimen.json保留实物未知项，不因仿真临时赋值而改成“已测”。

| 数据 | 当前处理 | 如何获取 | 影响/优先级 |
|---|---|---|---|
| 单板实际尺寸、厚度分布、质量 | 订单尺寸，商家密度1650 kg/m³ | 卡尺测长宽；低测力千分尺测中心和边缘多点；称重并记录是否含胶和传感器 | 高；刚度对厚度敏感 |
| 完整层数、层序、单层厚度、表面织物厚度 | 均匀50/50的0°/90°刚度混合；不指定真实层序 | 向供应商索取该批次铺层单、纤维/树脂型号；必要时用同批边角料制样观察截面 | 高；无法由“3K斜纹”唯一确定 |
| E1/E2/G12/泊松比 | Li 2012 T300/F593单层常数外部替代，板密度仍用商家值 | 同批材料证书或同批试样拉伸/剪切测试；整板模态/静挠度可校准部分等效刚度，不能唯一反演所有单层常数 | 高；本次做±25%整体弯曲刚度敏感性，范围不是统计置信区间 |
| 夹具净跨、夹持宽度、螺栓及预紧 | 周边20 mm固定条带，内边界理想固支；10/30 mm另算 | 测量并拍摄装配图；记录压条截面、接触材料、螺栓间距及紧固流程；测模态检查安装重复性 | 高；真实边界可能有滑移和转角 |
| 球材质、直径、质量、落高 | P2的8 mm钨钢球/160 mm落高；质量按14800 kg/m³推算 | 球材质证书；卡尺及电子秤；量释放点至首次接触的球底垂直距离 | 高；数值参考工况不是已执行实验 |
| 接触压入本构 | Hertz各向同性半空间代理，接触E=8.2 GPa、nu=0.3；系数0.5/2倍另算 | 同批板与同球进行已知支撑条件的力-压入测试，分离整体挠度；或仪器化冲击同步测力，再用独立工况验证 | 高；各向异性层合板不等于Hertz半空间；不能当成局部应力/损伤预测 |
| 阻尼及能量损失 | 0，采用保守机械基准 | 固定装配下测自由衰减或模态频响，区分结构/夹具/电路效应；多次回弹录像约束接触损耗 | 中高；当前晚期幅值可能偏大，不能用于吸收能量判断 |
| 实际落点及多次弹跳 | 中心及一个偏心点是规定数值输入 | 标尺标定录像；记录首次接触点、是否偏离和二次接触；定位真值独立于PZT估计 | 高；释放位置不等于实际接触位置 |
| PZT厚度、极化、电极覆盖、完整矩阵 | 只求15×15 mm名义贴片区域的基底应变；不加入贴片刚度/质量/电压 | 查该批次型号及完整数据表；测厚度和尺寸；核对极化/正负极；小信号LCR测电容和损耗 | 电压对接前必须；不同厂商PZT-5A不可无说明拼接 |
| 胶层材质、厚度、固化条件 | 未建模 | 保存胶型号和固化记录；用控厚工艺及同工艺见证样测厚；供应商数据或胶样测试 | 电压/应变传递前必须；未知时做范围分析 |
| 板卡真实型号、量程、滤波及同步 | 5 µs输出只表示200 kSPS采样；未模拟真实模拟滤波或量化 | 核对板卡手册/芯片丝印；同步输入已知小信号，测各通道增益、相位、噪声和饱和；保存驱动设置 | 高；标准AD7606约22 kHz模拟带宽，不能等同200 kHz带宽 |
| 接收电路及线缆 | 未建模；不输出V | 电路图、输入阻抗、线缆电容/长度、前放增益和保护方式；已知输入做整链路标定 | 电压对接前必须；PZT电荷源不能直接等同理想电压源 |
| 实物强度、分层/损伤判据 | 无损伤模型，不能判断本工况无损 | 同批材料强度/断裂韧度试验或可信证书；冲击前后独立无损检测，如具备条件的超声C扫 | 损伤研究前必须；机械波形变化不是损伤真值 |
| 实测响应 | 尚无 | 保留原始全通道时程及输入、边界、温度和异常记录；分开校准集与验证集 | 不能计算实验误差/定位准确率/电压吻合度 |

## 当前模型适用范围

可用于检查低阶固有频率、落球-板耦合过程和未知参数敏感性。它是Kirchhoff薄板Rayleigh-Ritz模型，不是3D有限元，不含横向剪切、转动惯量和面内拉伸；原始高频应变须同时满足空间收敛及薄板理论适用性，不能因离散加密就宣称高频导波或损伤已验证。

传感输出定义为上表面名义贴片区域的平均(epsilon_xx+epsilon_yy)。此量只是机械接收代理，既不是单独某个应变分量，也不是PZT应变或电压。
