# 3D 落球冲击模型：局部细化子模型 + 全局传感器响应

状态：已实现并实际运行。两级模型均已通过网格、时间步与能量验证，局部接触力与远场传感器应变均为**收敛后的结果**。仍是机械代理模型，**不是 PZT 电压、不是损伤预测、不是已标定的实物试件**。

本目录是 [impact_v1](../impact_v1/README.md) 的三维拓展。impact_v1 的 Rayleigh–Ritz 薄板**没有厚度方向自由度**，因此接触区应力、厚度剪切和薄板理论的适用边界都无法回答；本目录补的正是这部分。

## 1. 为什么是两级模型

一个网格无法同时满足两个要求：

| 需求 | 尺度 | 冲突 |
|---|---|---|
| 接触斑 | 半径约 **0.22 mm** | 需要分级局部网格 |
| 远场传感器 | 250×200 mm 的四分之一板 | 需要均匀网格 |

所以拆成两级：

- **第一级** [solve_impact_3d_local.py](solve_impact_3d_local.py)：冲击角分级加密，刚球单边非穿透约束，每步解 LCP 求出接触力与压力分布。产出 F(t)。
- **第二级** [solve_impact_3d.py](solve_impact_3d.py) 的 `run_prescribed`：均匀网格，由 F(t) 以集中力驱动，读出 16 个传感器位置的应变。

这个拆分的合法性依据是 Saint-Venant 原理 —— 在传感器距离上，远场响应由**合力时程**决定，而与这力在接触斑内如何分布无关。交叉验证见第 4 节。

## 3. 已验证的证据

### 3.1 材料与低频全局响应（与 impact_v1 对照）

| 验证项 | 结果 |
|---|---|
| 隐含平面应力刚度 D | D11/D22 差 **0.045%**、D66 **完全一致**、D12 差 1.39% |
| 一阶频率 | 薄板 122.52 Hz；3D 单调从上方收敛（dx=2.08 mm 时 124.66 Hz，**+1.7%**） |
| 均匀网格收敛 | 面内 100→200 单元：力变 6%；厚度 4→8 层：变 0.3% |

D 的差异来源明确：impact_v1 平均的是平面应力折减后的 Q，本模型平均的是完整三维 C。两者都报告，不掩盖。

### 3.2 局部细化子模型

刚球接触，满 0.5 ms（可跨窗口比较的一档，挠度与压入只有这两档）：

| h0 (mm) | 接触窗口节点 | 峰值接触力 | 中心挠度 | 残余压入 | 能量漂移 |
|---|---|---|---|---|---|
| 0.250 | 28 | 32.40 N | 311.0 µm | 2.13 µm | 1.19e-04 |
| 0.125 | 67 | 31.98 N | 310.0 µm | 1.26 µm | 3.99e-05 |

再往细的网格只在 50 µs 窗口运行（成本所限），仅用于观察峰值力的趋势 —— 接触力峰值出现在约 40 µs，故 50 µs 足以覆盖峰值，但**挠度与压入不能与前表跨窗口比较**：

| h0 (mm) | 接触窗口节点 | 峰值接触力 | 能量漂移 |
|---|---|---|---|
| 0.080 | 111 | 31.86 N | 2.06e-05 |
| 0.050 | 176 | 31.94 N | 1.30e-05 |

四档合力在 31.86–32.40 N 间无趋势波动（**1.7%**），挠度在 0.25→0.125 mm 加密时变化 0.3%，残余压入量单调下降（约束被越来越严格地满足）。

时间步加密（h0=0.125 mm，50 µs 窗口）：safety 0.5 → 0.25 时力 31.98 → 32.25 N、挠度 82.09 → 82.93 µm，一致到 **1%**。

`element_parts` 的六系数刚度展开与逐单元直接积分对比，误差 **2e-16**（机器精度，跨多种长宽比）。

## 4. 主要结论

### 4.1 薄板模型的局部响应不可信

同为 0.5 ms 窗口：

| 量 | impact_v1 薄板 | 3D 刚球接触 | 差异 |
|---|---|---|---|
| 峰值接触力 | 162.51 N | **32.0 N** | 薄板高 **5.1 倍** |
| 冲击点位移 | 112.2 µm | **310 µm** | 薄板低 **2.8 倍** |

两个方向互相自洽：3D 局部柔度更大 → 位移更大 → 球被接住得更软 → 接触时间更长、峰值力更小。原因是薄板的 Rayleigh–Ritz 截断把载荷点的奇异性正则化了。

**交叉验证**：子模型自身挠度 311.0 µm，第二级（同力时程驱动的均匀网格）给出 300.2 µm，差 **3.6%**。用完全不同的接触表述（预设赫兹压力分布）在 0.5 ms 得到 302 µm，与刚球接触的 310 µm 差 **2.6%**。三套互不相同的网格与接触处理落在同一范围。

安全可用的量：全局频率、远场传感器应变、厚度方向运动学。局部量（接触力、压入）以子模型为准，但见第 5 节限制。

### 4.2 传感器方向依赖

同一贴片、同一时刻，仅改铺设方向，测到的应变可差数倍。最近传感器（距冲击点 73 mm）：

| 读数 | 幅值 |
|---|---|
| 沿冲击方向投影（38°） | **196 µε** |
| 沿铺设轴投影（0°） | 55 µε |
| 面内不变量 εxx+eyy | 76 µε |

冲击方向投影是轴向投影的 **3.6 倍**。原因可解释：该点主应变方向 φ≈42°，与冲击方向 38° 几乎重合 —— 远场以径向变形为主，所以**朝向冲击点贴片的信号最强**。这也说明 P2 取"沿冲击方向的单元应变"不是随意选择。

四个象限内传感器的比值（冲击方向/轴向）分别为 1.29（S9）、3.26（S13）、3.56（S10）、4.31（S14），随主应变方向与铺设轴的夹角变化 —— 即方向依赖的强弱本身取决于贴片与主轴的相对取向。各片幅值还随距冲击点距离衰减（73→219 mm 对应 196→45 µε）。

## 5. 限制与未解决项

1. **能量口径**：局部子模型中，接触力按赫兹分布摊到多个节点，而间隙取自冲击角点，两者不是共轭变量，因此能量检查只是近似（漂移 ~1e-5）。改用共轭的贴片加权间隙会更差（力 401 N、漂移 61 倍），已试过并回退，**不要再试**。
2. **远场网格未做 h_max 收敛**：0.5 ms 时全局响应开始发展，远场 4 mm 网格的离散误差会进入结果，未单独量化。
3. **两级拆分的适用范围**：Saint-Venant 依据只在传感器距离成立；接触点附近的场不能由第二级读取。
4. **刚球假设**：钨钢球 E=530 GPa 比 CFRP 横向模量高 65 倍，当作刚体合理；但这是判断，不是实测。
5. **无** 损伤、分层、阻尼、塑性、PZT 质量与刚度、胶层、压电耦合、电路与采集链。输出**绝不可**标为电压。
6. **接触本构未标定**：单边非穿透是几何约束，不含真实分层压痕本构。

### 已作废的中间结论（留档以防重复）

本轮排查中先后提出三个诊断，**均被数据否定**：

| 诊断 | 否定依据 |
|---|---|
| 点载荷正则化是偏差主因 | 摊开接触斑后偏差仍在 |
| Gershgorin 界限在非均匀质量下低估 | 实测只低估 1.04 倍 |
| 显式积分失稳 | 步长减半漂移不降反升（10.1%→11.5%→14.4%）；真失稳必随步长消失 |

第三项指向真正的病因：能量口径不自洽，而非数值失稳。改用非光滑约束（约束不做功）后漂移从 ~1e-1 降到 ~1e-5。

此外：`mass_scaled_bound` 用 max Σ|K_ij|/√(m_i m_j)，除以 m_i 只在节点质量相等时等价。

## 6. 复算

仅需 NumPy 与 SciPy。

```powershell
# 主链：子模型 + 全局传感器响应，约 3 分钟
python run_study_3d.py --out study_3d

# 附带网格与时间步收敛扫描，约 15 分钟
python run_study_3d.py --out study_3d --convergence

# 单独运行
python solve_impact_3d.py --mesh 100 80 4 --modes 6 --out results/global
python solve_impact_3d_local.py --rigid --h0 0.00025 --z0 0.000125 --out results/sub
python solve_impact_3d_local.py --verify          # 单元刚度展开自检
python solve_impact_3d_local.py --h0 0.0025 --z0 0.0005 --growth 1.0 --hmax 0.0025
```

`--out` 拒绝覆盖已存在目录，重复研究请换新目录。输出目录里的 CSV/NPZ 为完整数据，留在本机；版本库只收 JSON 指标。

## 7. 文件

| 文件 | 用途 |
|---|---|
| `solve_impact_3d.py` | 均匀网格全局模型；`run` 用预设赫兹代理，`run_prescribed` 由力时程驱动并输出传感器应变 |
| `solve_impact_3d_local.py` | 分级网格子模型；`run` 用预设赫兹压力分布，`run_rigid` 用刚球单边非穿透约束 |
| `run_study_3d.py` | 两级主链与收敛扫描的编排，产出 `study_metrics.json` |
| `simulation_config_3d.json` | 求解输入；`provenance` 字段逐项标注出处 |
| `study_3d/` | 归档指标（JSON 入库，CSV/NPZ 留本机） |

两级共用同一套球参数与赫兹系数，保证差异只来自运动学与接触处理。

`run`（预设赫兹压力）保留是为了与 `run_rigid` 做对照，**不是**推荐用法；局部量请用 `run_rigid`。
