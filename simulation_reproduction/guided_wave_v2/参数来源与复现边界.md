# 主动导波分层散射：文献参数二维有限元参考算例

本版计算健康/分层结构的弹性波响应，作为后续 PZT 实验的机械传播基准。它不是照片试件的数字孪生，也不是知识库论文实测数据的精确复现。此前报告里的人工波形不能用作本版的物理验证证据。

## 1. 参数从哪里来

知识库根目录的齿轮 UGW–FAA–ELM 论文（PDF 第 5 页，实验装置部分）提供了主动 PZT 测试背景：SMART Layer、60 mm 间距、350 kHz 激励、24 MHz 采集、40 次平均，以及 Hysol EA9396/C-2 胶黏剂。其对象是钢齿轮；这些频率和结构参数没有直接移植到复合板。知识库 MSSP01 的 T300/环氧板为 500×500×5 mm，但缺少本求解所需的完整正交各向异性常数。Zhao 论文的织物碳纤维加筋板也不能仅凭“T300”名称套用单向层刚度。

因此按照用户允许的联网替代原则，采用 [Li 等，2012，正文 §4、表 1、§4.2](https://onlinelibrary.wiley.com/doi/10.1155/2012/659849) 的 T300/F593 参数。以下是这一独立参考材料，不是照片试件的实测值：

| 输入 | 使用值 | 来源/处理 |
|---|---|---|
| 单层 E1 / E2 / E3 | 128.1 / 8.2 / 8.2 GPa | 外部论文表 1 |
| G12 / G13 / G23 | 4.7 / 4.7 / 3.44 GPa | 同上 |
| ν12 / ν13 / ν23 | 0.27 / 0.27 / 0.20 | 同上；互易泊松比由柔度对称性确定 |
| 密度 | 1570 kg/m³ | 同上 |
| 厚度、层数 | 1.72 mm、8 层 | 外部论文 §4 |
| 铺层 | [0]₈ | 取论文中的单向板基准，未采用其准各向同性损伤案例铺层 |
| 原论文平面尺寸 | 500×500 mm | 本计算只保留 x 向 500 mm 截面，不求解板宽方向 |
| 激励 | 100 kHz、5 周期 Hann 窗正弦 | 外部论文 §4；时长 50 μs |
| 激励幅值 | 每侧峰值 1 N/m，同向法向线力 | **二维归一化选择**；原论文为三维点力 1 N，不能据此比较绝对幅值 |
| 分层长度 | 30 mm | 参考原文 30×30 mm 方形分层的一个截面尺寸；本版没有有限宽方形边缘 |
| 分层深度 | 中面，第 4/5 层之间 | 本算例选择；位置 z=0.86 mm |
| 分层 x 范围 | 235–265 mm | 本算例设计值，不是照片测量或原文图纸坐标 |
| 激励 x / 接收 x | 100 / 180、320 mm | 本算例设计值，分别观察缺陷前、缺陷后响应 |
| 边界 | 所有外表面自由，初始静止 | 理想化基准选择；没有照片中的夹具、加强筋或螺栓 |

选择单向板是为了先独立检验波传播和节点分离，不把未经验证的铺层旋转、胶层和接触效应同时混在一个模型中。该选择意味着不能宣称已经复现原文准各向同性板的损伤图。

## 2. PZT 数据与当前输出的关系

[厂商 PZT-5A/5H 数据表](https://info.piezo.com/hubfs/Data-Sheets/piezo-PZT-5A_PZT-5H-material-properties.pdf) 给出候选 3195STD 材料的典型值：密度 7700 kg/m³，d31=-175 pm/V，d33=350 pm/V，介电常数 K33ᵀ=1800。这只是可追溯的候选材料数据，**没有用于当前机械求解**。还不能确定最终贴片的尺寸、极化方向、完整机电矩阵、胶层厚度与模量、驱动阻抗和采集负载，因此不输出 PZT 电压。

当前激励沿用文献等效力建模思想：上下表面同向激励以产生反对称弯曲响应。接收量是顶部节点的法向位移 uz，单位 nm。图中接收标记代表观察点，不代表已建模的实际尺寸 PZT 贴片。单位宽度归一化也使数值幅值不能直接映射为某一电压下的真实有限宽板幅值。

## 3. 求解方法

采用 x-z 平面应变的正交各向异性线弹性 Q4 单元，每个节点有 ux、uz 两个自由度。由完整三维柔度矩阵求逆后选取 xx、zz、xz 子矩阵，保持 εyy=γxy=γyz=0。使用 2×2 Gauss 完全积分与集中质量，显式中心差分求解 M ü+K u=f(t)，没有手工添加传播延迟、衰减系数、散射波包或随机噪声。

分层内部的中面节点被复制，上下半板在该段不共享节点；裂尖保留连接。由此形成无黏结、无接触的开口界面，能产生波反射、透射及厚度方向响应变化。这个理想模型不包含闭合分层的拍击接触、摩擦、黏聚损伤演化或材料阻尼，故不能用于损伤扩展/强度预测。

时间步使用 M⁻¹K 绝对行和对最大特征值的上界，取保证稳定步长的 0.7 倍以内。边界自由反射真实保留，没有人为吸收带；晚期信号可能包含多次边界反射。差分为完全相同输入下的损伤响应减健康响应，不能把差分中的每一段都解释成一次孤立散射。

## 4. 验证与数据解释

运行三档网格：1000×8、2000×16、4000×32 个单元，对应 dx=0.5、0.25、0.125 mm，厚度方向每层 1、2、4 个单元。另对中等网格损伤工况减半时间步。`metrics.json` 报告接收波形相对 L2 变化，插值到共同时间点后计算；它不是相对实验的误差。

每次计算记录：总质量、刚体转动刚度残差、激励结束后的中心差分离散能量漂移、网格、稳定步长、节点数和步数。能量守恒只能说明离散系统和积分一致，不能证明模型与真实试件一致。缺陷位置和尺寸是输入，当前没有由信号反演损伤位置，也没有虚构定位精度或实验吻合率。

`receiver_signals.csv` 是完整输出时间序列；`*.npz` 保存采样位移、表面空间波场和时间；`experiment-results.png` 展示实验截面及波形；`wave-space-time.png` 展示时空传播。图上的厚度比例被放大，位移曲线与几何分开绘制，不能按画面尺寸读出真实变形。

## 6. 频散验证（2026-09-19 补做）

### 6.1 为什么必须做

此前的验证只覆盖离散自洽性（网格加密、半步长、能量漂移、刚体转动残差），这些**都不能说明模型是否以正确的速度传波**。对"测损伤散射"而言这是地基：波速错了，之后对散射波包的每一次归因都不可靠。此前报告里的"表观群速度 1773.48 m/s"是从包络峰值硬算的，混杂了模态与反射，不是频散意义上的模态速度。

### 6.2 解析参考的实现与自检

`dispersion.py` 求解与 FE **同材料、同厚度、同平面应变假设、同传播方向**的正交各向异性 Rayleigh–Lamb 行列式。判据用边界条件矩阵的**最小奇异值**（而不是行列式，后者元素跨越多个数量级），根由相速度扫描加局部精化得到。

解析实现本身先经各向同性严格极限验证（`dispersion.py --self-test`）：

| 判据 | 严格值 | 本实现 | 误差 |
|---|---|---|---|
| S0 长波极限 `sqrt(E/(ρ(1-ν²)))` | 5393.9127 | 5393.9107 | **3.8e-07** |
| 高阶分支高频极限 = Rayleigh 波速 | 2909.7314 | 2909 | **3.4e-04** |
| 截止频率下侧分支数 | 2（仅 A0、S0） | 2 | ✓ |
| 截止上方 A1 分离 | 存在且 < c_T | 2853 < 3122 | ✓ |

**实现过程中修正了两处错误**，记录以备复查：①极化比 `W/U` 的符号原写成负（由 `(A−C55p²)U = kp(C13+C55)W` 应为正），使矩阵在任何真实解处都不奇异；②`c_L`、`c_T` 处 `p→0` 使极化比发散，会在两个体波速度处制造假根，现以 0.2% 窄带排除。

### 6.3 FE 波速的提取方法

用 `frames` 里已保存的表面波场 u(x,t)，对时间做 FFT 后**拟合各频率下的空间相位斜率**得 k(f)。相位在 1 mm 采样间距下步进约 0.5 rad，无缠绕问题（此前用 140 mm 接收间距做相位差，需要解析辅助解缠绕，而 FE 与解析的微小差异使缠绕整数在错误频率跳变，提取的相速度出现 4% 的台阶且非单调，**该方法不可用**）。

拟合窗口必须落在 A0 在仿真时长内真正到达的区域：A0 约 1300 m/s，220 μs 内自 100 mm 激励点只走到 x≈386 mm。窗口取到 450 mm 会把没有信号的区域一并拟合，使 k 在 85 kHz 偏高 0.7%、115 kHz 偏低 1.2%，进而使群速度虚假偏差 8–13%。现取 x∈[140, 340] mm。

### 6.4 结果

A0 相速度（4000×32 网格）：

| f (kHz) | FE c_p (m/s) | 解析 (m/s) | 差异 |
|---|---|---|---|
| 95 | 1274.7 | 1268.9 | +0.46% |
| 100 | 1277.6 | 1286.4 | **−0.68%** |
| 105 | 1315.3 | 1302.8 | +0.96% |

网格加密（1000×8 → 2000×16 → 4000×32）给出 1280.3 / 1278.1 / 1277.6 m/s，相对解析的误差 0.48% / 0.65% / 0.68%，**收敛**。

**结论：A0 相速度经独立解析参考验证通过，100 kHz 处误差约 0.7%，全频段逐点误差在 ±1.3% 以内。**

### 6.5 未能完成的部分（如实记录）

1. **S0 未验证。** 激励是法向线力，A0 谱峰约为次强特征的 15 倍，而 S0 波数处**没有谱峰**（S0 面外位移分量极弱）。因此本验证只覆盖 A0。这是项目实际测量的分支（表面法向位移），但不能读作对 S0 的验证。
2. **群速度未达到验证精度。** 解析值 1745 m/s；包络峰值法给 1778（+1.9%），相位斜率法给 1817（+4.0%），**两种方法彼此不一致**，说明群速度的提取精度不足，不应宣称通过。
3. **k(f) 存在 ±1% 的振荡**（同一频率上逐点差异在 +1.20% 与 −1.33% 之间交替，无系统性趋势）。最可能来源是有限板长（500 mm）内 A0 波包与自由端反射叠加形成的驻波图案。群速度依赖 k 对频率的斜率，对这种确定性振荡敏感；这解释了第 2 点的量级。改进方向是延长板或加吸收边界，使波场在拟合窗口内不被反射污染。
